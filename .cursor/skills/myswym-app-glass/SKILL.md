# MySWYM App Glass (OPEN × Miracle)

**Source de vérité** : [`DESIGN.md`](../../../DESIGN.md) (racine repo). Toute modif UI app (et corrections landing) part de là. Ce skill est un rappel court.

## Direction

1. **Dock** : Accueil · Programme · Analyse · Historique (pas de Profil).
2. **Profil** : avatar top-right → écran plein (retour + crayon), réglages + infos nageur. Pas dans le dock.
3. **Binômes** : uniquement dans le Menu hamburger.
4. **Analyse** : km/séances, allure, analytics, badges, Strava.
5. **Historique** : dashboard séances terminées (hors Programme).
6. **Menu** : hamburger → modules + Premium.
7. Sons UI muteables.
8. **Typo** : une seule sans sobre (Geist / system), hiérarchie Miracle (`ms-type-page` 28 · `ms-type-section` 18 · `ms-type-display` chiffres · `ms-type-body` 15 · `ms-type-label`). Pas de Space Grotesk dans l’app. Corps `#4A5D72`, titres ink. Landing marketing : même famille soft mist.

## Interdit

- WebGL, abyss dark, empilement de chips Accueil
- Space Grotesk / titres « display » agressifs dans l’app loguée
- Labels UPPERCASE + tracking large (préférer sentence case + weight 500–600)
- Réutiliser `stitch_tableau_de_bord_myswym/**/DESIGN.md` (DA dark obsolète)
