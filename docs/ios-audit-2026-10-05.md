# Audit iOS, 5 oct. 2026 (build 33, pas de bump)

Corrections de l'audit, branche `feat/ios-apple-jws-verify`. Pas encore sur TestFlight.

## Code

- Reçus Apple : chaîne de 3 certificats, OID StoreKit, dates à `signedDate`. Plus de racine « n'importe où ».
- Achat : `finish()` seulement après `apple-iap-sync`. Achats différés écoutés au boot, liés via `appAccountToken`.
- Push : un jeton APNs ne reste pas sur l'ancien compte. Couper les notifs ou se déconnecter ne touche que cet iPhone. Rappels locaux annulés à la déconnexion.
- Retour OAuth / Strava : une URL n'est traitée qu'une fois. Strava iOS a un `state` aléatoire. Le lien de retour n'accepte plus `access_token` dans l'URL (mot de passe oublié : code PKCE + `reset=1`).
- `registerNativePush` ne repart plus à chaque séance cochée.
- `Info.plist` : plus de storyboard de scène, capacité `arm64`. Webhook : environnement Sandbox / Production cohérent avec la transaction.

## À tester sur un vrai iPhone

1. Achat sandbox, puis couper le réseau juste après le paiement : au retour du réseau, le compte doit passer Premium (Restaurer aussi).
2. Ask to Buy (ou un achat approuvé plus tard) : Premium sans rouvrir la feuille d'achat.
3. Deux comptes sur le même iPhone : après déconnexion, l'ancien compte ne reçoit plus les notifs de binôme ni de support. Couper les notifs ne doit pas couper un autre appareil.
4. Connexion Google à froid (app tuée) et Strava à froid : une seule fois, pas d'erreur au second passage.
5. Mot de passe oublié : le mail ouvre l'app et le formulaire, sans coller un jeton dans le lien.
6. L'app démarre encore après le retrait du storyboard de scène (`UISceneStoryboardFile`).
